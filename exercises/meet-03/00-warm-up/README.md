# Level 0 — Warm Up dan Recall

## Tujuan

Mengaktifkan kembali variable, tipe data, `print()`, dan f-string dari Meet 01.
Belum ada database pada level ini.

## Urutan

1. `01_tebak_output.py` — tulis prediksi, baru jalankan.
2. `02_ubah_data.py` — ubah satu data dan amati output.
3. `03_tebak_output_data.py` — enam prediksi list dan dictionary.

## Hint

1. Tanda kutip membuat nilai menjadi string.
2. `type()` menunjukkan tipe nilai.
3. F-string memakai pola `f"... {variable} ..."`.

## Checkpoint

- [ ] Bisa membedakan string dan integer.
- [ ] Bisa menjelaskan bahwa variable menyimpan satu nilai.
- [ ] Sudah mengubah data tanpa mengubah format output.
- [ ] Sudah menulis enam prediksi sebelum menjalankan file terakhir.
