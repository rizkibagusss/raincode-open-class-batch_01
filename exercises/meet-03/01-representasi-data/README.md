# Level 1 — Representasi Data

## Tujuan

Mengubah data transaksi dari beberapa variable menjadi satu dictionary, lalu
menyimpan banyak dictionary di dalam list.

## Urutan

1. `01_variable_to_dictionary.py`
2. `02_access_dictionary.py`
3. `03_list_transactions.py`

## Expected akhir

```text
Kopi Susu | Rp25000
Makan Siang | Rp35000
Transport | Rp15000
```

## Checkpoint

- [ ] Bisa menjelaskan key dan value.
- [ ] Bisa membaca dan mengubah value dictionary.
- [ ] Bisa menambahkan dictionary ke list dengan `append()`.
- [ ] Bisa melakukan loop terhadap list of dictionaries.
