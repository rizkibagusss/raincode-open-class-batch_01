# Level 2 — CRUD di Memory

CRUD adalah empat operation yang sering dilakukan terhadap data:

| CRUD | Makna | Operation list |
|---|---|---|
| Create | Menambah data | `append()` |
| Read | Membaca data | loop |
| Update | Mengubah data | cari ID lalu ubah value |
| Delete | Menghapus data | cari target lalu hapus |

Kerjakan `01_create.py` sampai `04_delete.py`, lalu gabungkan pemahamanmu di
`05_crud_memory.py`.

## Checkpoint

- [ ] Bisa menambahkan dictionary baru.
- [ ] Bisa membaca data dengan loop.
- [ ] Bisa mencari data berdasarkan ID, bukan posisi list.
- [ ] Bisa mengubah dan menghapus satu target.
- [ ] Bisa menjelaskan mengapa data ini belum persistent.
