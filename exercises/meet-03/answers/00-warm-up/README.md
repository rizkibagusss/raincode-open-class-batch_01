# Jawaban Level 0

`01_tebak_output.py` menghasilkan:

```text
Kopi Susu
25000
<class 'str'>
<class 'int'>
```

`nama` menyimpan string karena nilainya memakai tanda kutip. `total` menyimpan
integer karena ditulis sebagai angka tanpa tanda kutip.

Bandingkan `02_ubah_data.py` di folder ini dengan pekerjaanmu. Perubahan nilai
tidak memerlukan perubahan format `print()` karena variable menjadi sumber data.

Jawaban `03_tebak_output_data.py`:

```text
2
Kopi Susu
True
60000
3
{'id': 1, 'nama': 'Kopi Susu', 'total': 30000}
```

Soal 4 menjumlahkan nilai `total` dari dua dictionary. Soal 5 menunjukkan bahwa
`append()` mengubah panjang list. Soal 6 mengubah value pada dictionary pertama.
