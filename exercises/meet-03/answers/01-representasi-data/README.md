# Penjelasan Level 1

- Dictionary menyatukan atribut milik satu transaksi.
- Key seperti `nama` dan `total` berfungsi sebagai label data.
- List menyimpan banyak dictionary.
- Setelah `fetchall(dictionary=True)` nanti, bentuk data dari MySQL akan terasa
  familiar karena kembali sebagai list of dictionaries.
