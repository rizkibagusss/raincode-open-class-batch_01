# Penjelasan Jawaban SQL

Bug pertama kehilangan huruf `T` pada `SELECT`. Bug kedua memakai `nominal`,
padahal `setup.sql` mendefinisikan column `total`.

Untuk UPDATE dan DELETE, ID pada answer hanyalah contoh. Selalu jalankan SELECT
untuk menemukan ID aktual di database lokalmu. Sumber kebenaran target adalah
hasil SELECT, bukan asumsi urutan ID.
