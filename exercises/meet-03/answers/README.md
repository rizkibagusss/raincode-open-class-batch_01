# Answer Key — Buka Setelah Mencoba

Folder ini adalah pembanding, bukan jalan pintas. Sebelum membuka jawaban:

- kerjakan TODO dari atas ke bawah;
- gunakan maksimal tiga hint;
- jalankan dan baca error;
- coba sendiri minimal 15–20 menit.

Ketika pendekatanmu berbeda tetapi hasil dan perilakunya benar, itu tidak masalah.
Bandingkan terutama alur data, target ID, parameter query, dan commit.
