# 01 — Mengontrol Data Sebelum Flask

Bagian ini mendampingi halaman 9–12 modul dan mengingatkan kembali Pertemuan 01.

## Demo Python

```powershell
python data_sementara.py
```

Masukkan `Kopi Susu` dan `25000`. Satu transaksi dibentuk sebagai `dict`, lalu
ditambahkan ke `list`. Tutup dan jalankan ulang program untuk membuktikan list
hanya hidup di memory proses Python.

## Demo browser

Buka `index.html`. Masukkan dua field dan amati table berubah tanpa reload.
Minta peserta memprediksi hasil refresh sebelum tombol refresh ditekan. Array
JavaScript juga merupakan penyimpanan sementara.

## Pertanyaan pengarah

1. Di mana dictionary disimpan ketika program masih berjalan?
2. Apa persamaan `list.append()` dan `array.push()`?
3. Apakah data yang sudah terlihat di table otomatis permanen?
4. Masalah apa yang akan muncul jika dua user memakai list yang sama?
