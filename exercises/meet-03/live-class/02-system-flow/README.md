# 02 — Peta Sistem Interaktif

Buka `index.html`, lalu klik **Mulai perjalanan data**. Diagram akan menyorot
perjalanan nama dan total belanja dari browser sampai MySQL dan kembali menjadi
table.

Tujuan aktivitas:

- membedakan frontend, backend, database, dan output;
- mengenali HTTP serta MySQL Connector sebagai jembatan;
- melihat hubungan Pertemuan 01, 02, 03, dan materi lanjutan;
- menjelaskan bahwa data tidak “langsung lompat” dari form ke database.
