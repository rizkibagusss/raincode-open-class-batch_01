# Live Class Meet 03 — Jalur Sesuai Modul

Ikuti folder secara berurutan. Setiap demo melanjutkan data yang sama:
`{"nama": "Kopi Susu", "total": 25000}`.

| Tahap | Fokus | Bukti belajar |
|---|---|---|
| [`01-data-sementara`](01-data-sementara) | Variable, dict, list, browser memory | Data muncul realtime lalu hilang setelah refresh |
| [`02-system-flow`](02-system-flow) | Frontend–backend–database | Peserta dapat menceritakan perjalanan satu data |
| [`03-database-mysql`](03-database-mysql) | Struktur DB, desain ringan, SQL | CRUD langsung pada `transactions` |
| [`04-python-mysql`](04-python-mysql) | Connector dan `db.execute()` | CRUD Python tanpa Flask |
| [`05-flask-crud`](05-flask-crud) | HTTP method dan Flask API | Data tetap ada setelah refresh |
| [`06-read-project`](06-read-project) | Membaca project per fitur | Menelusuri POST dari UI sampai query |
| [`07-debugging`](07-debugging) | Debug berdasarkan layer | Menemukan penyebab empat kasus bug |
| [`08-mini-challenge`](08-mini-challenge) | Check dan latihan bertingkat | Modifikasi kecil secara mandiri |

Catatan pengajar: jangan menjalankan semua kode sekaligus. Berhenti setelah tiap
lapisan dan tanyakan, “Saat ini data berada di mana?” serta “Siapa yang mengubah
data ini?”
